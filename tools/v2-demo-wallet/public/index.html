What this demo checks

The wallet creates actual AuthV2 and role proofs using pinned SDK and circuit files. OPS verifies them against this demo issuer’s identity-state service, records its own session, and asks you to confirm. This wallet never issues an OPS token or browser session.

The application’s Reth node, indexer and creation observer run separately. The local identity-state service is an explicit test fixture; it does not represent a hosted Privado issuer or Azure tenant.
